Omniglass release {{ .Release.Name }} is installed in namespace {{ .Release.Namespace }}.

1. Wait for the server to become ready:

     kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "omniglass.fullname" . }}

2. Reach the console:
{{- if .Values.ingress.enabled }}

     https://{{ .Values.ingress.host }}/web

   (routed by the {{ .Values.ingress.className }} ingress controller; TLS at the edge)
{{- else }}

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "omniglass.fullname" . }} 8080:{{ .Values.service.port }}

   then open http://localhost:8080/web
{{- end }}
{{- if .Values.bootstrap.enabled }}

3. The first owner ({{ .Values.bootstrap.username }}) was created by the bootstrap init
   container, which prints its one-time bearer token. Read it from the logs:

     kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "omniglass.fullname" . }} -c bootstrap
{{- end }}
{{- if not .Values.postgres.enabled }}

NOTE: postgres.enabled is false, so the server dials the externalDsn you supplied.
{{- end }}
{{- $keySecret := include "omniglass.encryptionKeySecret" . }}

BACK UP THE ENCRYPTION KEY. Every secret Omniglass stores in Postgres is sealed
under the key in Secret {{ $keySecret }}; lose it and those secrets cannot be
read back, by anyone. Read it out now and keep it somewhere outside this cluster:

     kubectl -n {{ .Release.Namespace }} get secret {{ $keySecret }} -o jsonpath='{.data.encryption-key}' | base64 -d
{{- if not .Values.encryptionKey.existingSecret }}

The chart generated this key once and reuses it on every upgrade. helm uninstall
keeps the Secret, so a reinstall of release {{ .Release.Name }} into this namespace finds
the same key; deleting the Secret by hand loses it.
{{- end }}
{{- if .Values.persistence.enabled }}

Durable state (the data directory and the bus's unlanded telemetry) is on
PersistentVolumeClaim {{ include "omniglass.fullname" . }}-data, which helm uninstall also keeps.
{{- else }}

persistence.enabled is false: the data directory is an emptyDir, so telemetry the
bus accepted but had not yet written to Postgres is lost when the pod restarts.
{{- end }}
