- **Date:** 2026-10-26 | **Status:** Accepted | **Pages:** [identity and access](/architecture/identity-access/), [collection](/architecture/collection/)
- **Decision:** (#1185, under epic #1146.) The credential stamp and the webhook receiver read one answer to "who is the client", from `internal/clientaddr`: the peer, unless the peer is trusted, in which case the forwarded header (every line, in order, its last 512 bytes) is walked from the right past every trusted hop to the first untrusted one, a malformed hop stopping the walk at the last good address. The trusted set is `OMNIGLASS_TRUSTED_PROXIES`: comma-separated CIDRs or bare addresses, a list replacing the default whole, `none` believing no proxy, and an entry that is neither failing the server's boot rather than trusting more or less than was meant. Unset, it is the loopback and private ranges, the built-in set #1024 shipped. The webhook source keeps its /64 grouping for IPv6; the credential stamp records the whole address.
- **Context:** The session and token stamp took the first `X-Forwarded-For` hop from any peer, so a client reaching the server directly could record any address it named, while the webhook receiver (#1024) already parsed the header and believed it only from a private peer. The two disagreed on who the client was, and neither could be told about a proxy on a public range. The review's confirmation pass noted that the private-range default also trusts a port forwarder presenting its own private address (Docker's userland proxy for an IPv6 client, rootless forwarders); defaulting to loopback only would close that, but would make every chart deployment (whose Traefik sits on a pod address) record its ingress as every client until the chart declares its range, and the chart has no environment passthrough yet. The default therefore stays, and the loopback-only default is filed as its own decision with the chart value it needs.
