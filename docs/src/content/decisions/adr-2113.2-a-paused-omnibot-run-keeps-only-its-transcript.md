- **Date:** 2026-11-17 | **Status:** Accepted | **Pages:** [AI](/architecture/ai/), [connect an agent](/guides/agents/#carrying-a-conversation-on)
- **Decision:** (#2113, on the loop's pause, #2120, and the conversations of [ADR-2113](/architecture/decisions/#adr-2113-a-persons-omnibot-conversations-are-theirs-alone).)
  1. **A kept transcript is not a pending approval.** A run that paused on an `ask` stores the
     conversation with a marker naming the call it waits on. The server never runs, approves,
     expires or notifies on that marker: it is the transcript's last word, kept for its owner.
  2. **The owner's client decides it.** The owner continues the conversation in their own client,
     which rebuilds the proposal from the transcript's open call and the tools as they are now (a
     marker naming no open call is refused) and decides it as an inline ask is decided. The approval
     stays client-side
     ([ADR-2063](/architecture/decisions/#adr-2063-an-install-sets-always-ask-or-never-per-class-of-operation-for-every-agent)),
     and the eventual call is the owner's agent's like any other, re-checked against their grants and
     the policy when it is sent.
- **Context:** An unattended run (an event rule's omnibot step, #2126) has no terminal to ask on. The
  2026-11-16 ruling keeps approvals client-side with no server-side pending approvals; this is how a
  paused run survives until its owner returns without the server holding a decision.
- **Limits:** A transcript stored with an open call and no marker (a client that keeps a turn without
  its marker; the CLI keeps both in one append) is not asked about that call on resume (#2129).
- **Not chosen:**
  - **Storing the proposal itself.** A stored proposal would carry the tool's policy and arguments as
    they were when it paused; rebuilding from the open call and the live tools means a policy
    tightened since is the one applied.
  - **A server-side approval queue.** The 2026-11-16 ruling rules it out: the server would hold a
    decision that is the owner's client's to make.
