The example fleet's components are named by the platform, whose counter runs across a whole stem in a
room, so Boardroom A's only wireless microphone read "Wireless Microphone 3" after two ceiling ones.
The seed now labels a component that staffs a slot the way the scale lab does: its type's label, and its
place among the slot's components when the slot holds several, a lone one unnumbered. A component in no
slot (a spare racked in a bay) still reads from the shipped label rule, which keeps that rule's demonstration.
