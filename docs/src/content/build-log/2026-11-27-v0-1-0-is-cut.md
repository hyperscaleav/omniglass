title: "v0.1.0 is cut, by hand, as the first public release (#2652)"
date: 2026-11-27
refs: [2652, 1940]
---

The first release ships the whole history (about 975 PRs; `v0.0.0` is a placeholder tag, never a
release), more than a GitHub Release body can list, so `v0.1.0` was cut by hand: a release commit set the manifest and `version.txt`
to `0.1.0`, the Release was created on it with a written summary and a compare link, and
`release.yml` built its image and binaries. release-please counts every later release from `v0.1.0`.
