`make perf-check SIZE=1000` now has a baseline to gate against. `corporate-1000.json` was generated by
`omniglass lab perf baseline --size 1000` from main's build on a throwaway test VM (8 cores, 16 GiB), the
host class the 1000 rung moved to (#1780), and committed unedited.

The laptop attempt had refused: metric rows a minute spread 2.6 percent against a 2 percent tolerance,
which was each node's report window drifting later by its take's lateness (#1779). With the windows on a
grid, the three runs read 60,559, 60,470 and 60,611 rows a minute, a 0.23 percent spread, and every figure
settled inside its tolerance.

A check of the 1000 rung on the same host class gates every figure; anywhere else the host-dependent
times and usage read reported, as the 300 rung's do off a GitHub runner.
