---
title: "Every Node toolchain runs Node 26 from one pin, .nvmrc (#2170)"
date: 2026-11-25
refs: [2170]
---

`.nvmrc` holds the Node major (26) and is the only place it is written. Every `setup-node` step reads it through
`node-version-file`, the Dockerfile's web stage is `node:26-bookworm-slim`, the session hook reads it, and
`engines.node` in `web/` and `docs/` asks for 26 or newer. `scripts/check-node-pin.sh` fails when any of them names
another major; `make preflight` and the image workflow run it beside the Go pin check. Node 26 no longer ships
corepack, so the docs scripts and pages call `pnpm` directly and the contributor prerequisites install pnpm 10.
