The perf gate no longer runs in CI. The `perf` workflow and its `run:perf` label are gone, and
`corporate-300.json` was regenerated by `omniglass lab perf baseline --size 300` from main's build on a
throwaway test VM (8 cores, 16 GiB), the host class `corporate-1000.json` came from, and committed
unedited. A check of either rung on that host class now gates every figure, times and usage included
(ADR-1787).
