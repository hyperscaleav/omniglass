---
title: "The console's API client is generated by orval (#1619)"
date: 2026-11-09
refs: [1619, 1465]
---

`npm run gen:api` now runs orval over `api/openapi.json` into `web/src/api/api.gen.ts` (every
schema as a type, one typed function per operation, all sending through the client's `ogFetch`),
and `scripts/gen-api-paths.mjs` indexes those operations by route into `paths.gen.ts`. `client.ts`
types the existing `api.GET(route, { params, body })` calls off that index, so every data layer
changed only its type imports; openapi-typescript and openapi-fetch are gone from the lockfile and
TypeScript is on 7 with no peer overrides. `client.test.ts` pins the request the client builds
(path encoding, query, body, credentials, token, the 204 and error reads) and the compile-time
refusals, and two page tests that relied on the old client's microtask timing now wait for their
outcome (ADR-1619).
